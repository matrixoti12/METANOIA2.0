USO RECOMENDADO

1. Extrae este archivo RAR.
2. Abre la carpeta extraída como proyecto o adjunta los tres assets a Claude Code.
3. Abre PROMPT-CLAUDE-SCROLL-WORLD.md.
4. Copia y pega el prompt completo.
5. Permite que Claude instale la habilidad oso95/scroll-world.
6. No apruebes gastos de generación de videos si Claude no explica antes el costo.
7. Cuando Claude entregue el código, llévalo de regreso al proyecto original para adaptarlo a React + Vite.
